# 非洲驻华记者台领域约定

## 身份

- 所有业务身份由调用方提供的稳定标识表示（经 `x-actor-id` 注入），角色为
  `journalist`（记者）、`editor`（编辑）、`security`（安全值班）、`admin`（管理员）。
- 受控运行环境中由网关 / mTLS 完成真实鉴权，本服务信任网关注入的身份。

## 时间

- **事件时间**（`eventTime`）：事情在现场发生的时间，可由客户端随离线操作上报，
  但不得晚于服务器接收时刻。
- **接收时间**（`receivedAt`）：服务端记录入库的时间，始终取自可信服务器时钟。
- 当前时间只增不减（持久化单调时钟）：进程重启、系统时间回拨都不会使已到期的
  授权重新有效、已逾期的确认/失联窗口重新打开。

## 分层

| 层级 | 内容 | 存储 |
| --- | --- | --- |
| tier 1 | 公开行程 | 明文 |
| tier 2 | 受限采访计划 | AES-256-GCM 密封，授权按层级 + 主题/来源范围判定 |
| tier 3 | 加密消息来源 | 同上，必须绑定 `sourceId`，通常仅签发来源级授权 |

授权含 `expiresAt`，到期后密文保留但不可解密；重新授权后可再次访问历史密文。

## 事件与确认

- 临时变更以事件传播，必须带 `deadline` 确认期限与明确受众（按人或角色）。
- 受众逐人确认；逾期未全员确认自动转 `overdue` 并写审计，迟到确认仍有效。
- 非受众看不到事件标题与摘要；受众名单只对发布方与值班角色开放。

## 安全报平安

- 每个进行中行程有报平安间隔 `intervalMs` 与宽限 `graceMs`，按风险等级
  （low/standard/high）决定升级路径。
- 位置以密文信封保存（AAD 绑定该次报平安记录），仅 security/admin 可解密。
- 升级事件与审计载荷只含记者标识、风险等级与升级级别，**不含定位**；
  记者之间互不可见安全状态与位置。

## 费用

- 预支有剩余额度；票据核销按 vendor + invoiceNo + date + amount + currency
  指纹去重，超额、币种不一致、代他人核销一律拒绝。

## 离线同步

- 弱网操作通过 `/sync` 回传：`opId` 保证幂等（重复回传不重复生效），
  记录更新带 `baseVersion`，服务端版本已前进时逐条返回冲突（409），
  同批其他操作不受影响。

## 审计

- 审计记录为追加式哈希链，不得以覆盖方式修改，不可删除；
  每条含前一条哈希，启动时重放校验，编辑可通过 `verify` 接口核验
  内容哈希、密文完整性与账本锚点，而无需获得明文读取授权。
