# 非洲驻华记者台领域约定

服务采用事件时间与接收时间分离的记录方式。所有业务身份由调用方提供的稳定标识表示，审计记录不得以覆盖方式修改。

## 分层数据

数据按密级分三层保存，访问策略逐层收紧：

| 层 | 数据 | 读取条件 |
| --- | --- | --- |
| 公开（public） | 公开行程 | 任何已认证成员 |
| 受限（restricted） | 采访计划 | restricted 密级，且为负责人/管理员/持有效采访授权 |
| 加密（confidential） | 消息来源 | 仅来源负责人与被授权人；管理员也不可读 |

来源内容在客户端以 AES-256-GCM 加密，内容密钥用接收方 RSA 公钥（OAEP）包裹后登记，服务端只保存密文与包裹密钥，不持有明文密钥。编辑核验报道链路时只能取得哈希与元数据。

## 变更事件

对行程与计划的临时变更以事件形式传播：事件携带 `confirmBy` 确认期限与确认人名单，全员确认后补丁才生效；逾期未确认自动失效并通知提议人。失效由惰性 sweep 推进，重启后照常执行。

## 安全签到与失联升级

失联等级完全由“最近一次签到时间 + 当前时间”推导，不依赖内存定时器，进程重启后自然继续计时。升级阈值按记者风险等级缩放（高/中/低 = 0.5/1/2 倍签到间隔）：

- L1：提醒记者本人；
- L2：通知责任编辑，**不含定位**；
- L3：通知安全角色，附最后已知位置。

精确定位仅对本人与安全角色开放。

## 费用

预支按 `idempotencyKey` 幂等；票据号在同一记者名下唯一；核销一次性且累计不得超过预支额。

## 采访授权

授权携带 `[validFrom, validUntil]` 有效期。每次访问实时判定有效期，到期即收紧（惰性落盘为 expired 并写审计）；撤销立即生效。

## 离线回传

现场笔记携带 `baseVersion` 回传。与服务端版本不一致即登记冲突：保留服务端快照与客户端补丁双方内容，由人工选择 server/client/merged 解决，绝不静默覆盖。

## 报道链路核验

报道发布时对每条引用（计划/来源/笔记）计算哈希承诺并串联成链。核验重算引用哈希与链式结构：来源使用密文哈希，无需解密，因此编辑可以验证链路完整性而无法借此看到未授权的来源信息。

## 审计

审计日志为追加式 JSONL，条目以哈希链串联（`prevHash` + 条目哈希），任何篡改都会断链；纠错只能追加新条目。
